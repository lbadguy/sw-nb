# SW Happy Birthday Page Topology

Target: `https://landonorris.com/` at 1440 x 1000 and 390 x 844. The implementation is intentionally isolated at `/swhappybirthday/` and adapts the source site's visual system to the supplied birthday portraits.

1. Fixed navigation: wordmark, center monogram, lime action, animated menu control.
2. Hero: full-viewport portrait, layered visor, small event card, mobile party control.
3. Message: dark contour field, horizontal type loop, monochrome portrait, short dedication.
4. Manifesto: extra-tall scroll field with a sticky oversized mixed-serif statement.
5. Moments: warm-grey scattered portrait wall, offset captions, quote, lime script-like label.
6. Day one / real one: opposing portraits around a centered two-column title lockup.
7. Hall of fame: black six-card archive with alternating vertical rhythm and image treatments.
8. Birthday edition: oversized champion copy, physical poster treatment, number-one stamp.
9. Social ticker: closing marquee that bridges the light page to the dark footer.
10. Footer: lime frame, arched dark panel, portrait, navigation, final birthday message.

The page uses regular document scroll. Sticky behavior is limited to the manifesto. Navigation remains fixed and changes foreground treatment based on the visible light/dark section.
